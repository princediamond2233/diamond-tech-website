# Diamond Tech V5 — Visual Website Builder

V5 upgrades Page Studio into a component-based Visual Website Builder.

Components: Text, Photo, Video, Call to Action, Quote, Statistic.

Each block supports editing, media selection, layout, alignment, background, optional buttons, visibility, duplicate, delete and drag reordering.

Workflow: choose page → add components → edit → reorder → preview desktop/tablet/mobile → Save Draft → Publish → restore revisions.
