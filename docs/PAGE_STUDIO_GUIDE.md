# Page Studio Guide

1. Open **Control Station → Page Studio**.
2. Choose the page.
3. Add Text, Photo or Video.
4. For media blocks, select a previously uploaded item from Media Library.
5. Add a title, caption and optional text under the media.
6. Drag blocks to reorder them.
7. Tick Publish section for sections that should appear publicly.
8. Click Publish. A revision snapshot is created before publishing.
9. Use Revision History to restore an earlier state.

Use Media Library first when you need a new image or video.
