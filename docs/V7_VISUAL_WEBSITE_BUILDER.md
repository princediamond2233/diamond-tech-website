# V7 Visual Website Builder

V7 keeps the Diamond Tech visual direction while expanding the Control Station into a practical page-building workflow.

## V7 additions
- Visual page templates for Landing, About, Services, Portfolio and Contact pages.
- True canvas reorder workflow with drag/drop plus move controls.
- Component duplication, visibility controls and undo/redo history.
- Media Library picker inside the page inspector; administrators can select uploaded images/videos instead of manually pasting URLs.
- Responsive Desktop / Tablet / Mobile preview controls.
- Revision history and restore workflow.
- Keyboard shortcuts: Ctrl/Cmd+S for draft save, Ctrl/Cmd+Z undo, Ctrl/Cmd+Y redo, Escape closes the media picker.
- Clear unsaved/saved status.
- Existing live CMS components remain available: services, portfolio, testimonials, founder, contact, gallery, FAQ, team and logo strip.

## Safety
Templates replace only the selected page's canvas. Save a draft first if the current layout needs to be preserved.

## Build
Run the normal project install/build scripts. This source package has not been dependency-installed or fully compiled in the generation environment, so final Windows build verification should be performed on the target development machine/CI runner.
